# Ativar o perfil público do GitHub

O arquivo [PROFILE-README.md](PROFILE-README.md) está pronto como conteúdo do perfil público do autor.

Para que o GitHub o mostre na página do usuário, é necessário criar um repositório público com o nome **exatamente igual ao nome de usuário**:

`nissieloeulirico`

Depois:
1. Abra https://github.com/new.
2. Em **Repository name**, escreva `nissieloeulirico`.
3. Selecione **Public**.
4. Crie o repositório.
5. Copie todo o conteúdo de `PROFILE-README.md` deste acervo para o arquivo `README.md` do novo repositório.

O GitHub reconhece esse repositório especial e exibe seu README no perfil: https://github.com/nissieloeulirico

Não crie outro repositório com nome parecido: precisa corresponder exatamente ao usuário. A conexão disponível nesta sessão permite editar arquivos de repositórios existentes, mas não criar um novo repositório de perfil.
