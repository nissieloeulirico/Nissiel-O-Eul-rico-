Sobre o acervo

Esta biblioteca apresenta edições digitais de leitura. Os arquivos Markdown no repositório são as fontes textuais de referência; o histórico de commits registra as alterações documentais.

A autoria das obras pertence a Nissiel, O Eulírico. Esta biblioteca organiza e apresenta os textos, sem substituir sua publicação oficial nem alterar os arquivos-fonte.
