Sobre o acervo

Esta biblioteca apresenta nove edições digitais de leitura, derivadas dos arquivos Markdown disponíveis no repositório. O catálogo geral identifica as publicações do site oficial e aponta para as respectivas páginas de leitura. O histórico de commits registra as alterações documentais.

Para conhecer o autor e percorrer o acervo completo, visite o perfil autoral e o Acervo Geral.

A autoria das obras pertence a Nissiel, O Eulírico. Esta biblioteca organiza e apresenta os textos, sem substituir sua publicação oficial nem alterar os arquivos-fonte.
