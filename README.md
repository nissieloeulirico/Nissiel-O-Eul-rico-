# Nissiel, O Eulírico

**Acervo literário e autoral**

Este repositório reúne e organiza obras de **Nissiel, O Eulírico**. É o arquivo de referência dos textos em formato Markdown, com registros das versões e histórico das alterações.

## Acesse o acervo

- **Site oficial:** [Nissiel, O Eulírico](https://nissieloeulirico.wordpress.com/)
- **Biblioteca de leitura:** [Acervo Geral no WordPress](https://nissieloeulirico.wordpress.com/acervo/)
- **Poemas publicados:** [Poemas](https://nissieloeulirico.wordpress.com/poemas/)
- **Catálogo deste repositório:** [CATALOGO.md](CATALOGO.md)

## Como este arquivo está organizado

- `CATALOGO.md` funciona como índice geral das obras registradas.
- `poemas/` reúne os poemas arquivados em Markdown.
- Cada registro do catálogo aponta para o arquivo correspondente e, quando disponível, para a publicação pública.

## Critérios do acervo

- A versão identificada como **Definitiva** é a versão de referência registrada no momento.
- Alterações posteriores devem ser feitas com atenção à integridade do texto e registradas no histórico de commits.
- O arquivo no GitHub e a publicação no WordPress são referências complementares: o WordPress oferece a leitura pública; este repositório mantém os arquivos organizados e seu histórico.
- A inclusão de uma obra no catálogo não substitui sua publicação nem altera sua autoria.
