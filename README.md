# Nissiel, O Eulírico

**Acervo literário e autoral · Biblioteca de textos · Documentação pública**

Este é o repositório oficial do acervo de **Nissiel, O Eulírico**, pseudônimo literário de **Tiago da Silva Santos**, escritor independente, filósofo, poeta e pensador brasileiro. Reúne fontes textuais, documentos de apresentação, registros de composição e edições digitais de suas obras. Idioma principal: português brasileiro (pt-BR).

## Organização do repositório

- `poemas/`: fontes dos poemas em Markdown.
- `narrativas/`: fontes de contos e narrativas.
- `entrelinhas/`: memórias de composição, mantidas separadas das obras.
- `docs/`: edições HTML de leitura, índices e arquivos de apoio.
- `BIOGRAFIA.md`: apresentação biográfica.
- `CATALOGO.md`: catálogo das publicações.
- `PENSAMENTO-E-ORGANIZACAO-DA-OBRA.md`: documento filosófico e estrutural.
- `IDENTIDADE.md`: referência de identidade autoral.
