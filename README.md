# Nissiel, O Eulírico

**Acervo literário e autoral · Biblioteca digital**

Este repositório reúne e organiza obras de **Nissiel, O Eulírico**. É o arquivo de referência dos textos em Markdown, com catálogo, identificação autoral e histórico das alterações.

## Acesse
- **Site oficial:** [Nissiel, O Eulírico](https://nissieloeulirico.wordpress.com/)
- **Acervo geral:** [WordPress](https://nissieloeulirico.wordpress.com/acervo/)
- **Poemas publicados:** [WordPress](https://nissieloeulirico.wordpress.com/poemas/)
- **Biblioteca digital:** [GitHub Pages](https://nissieloeulirico.github.io/Nissiel-O-Eul-rico-/) — endereço previsto; requer ativação em Settings → Pages.
- **Catálogo:** [CATALOGO.md](CATALOGO.md)
- **Identidade autoral:** [IDENTIDADE.md](IDENTIDADE.md)

## Estrutura
- `poemas/`: arquivos-fonte em Markdown.
- `docs/`: biblioteca digital de leitura, com páginas HTML, tema de papel marfim, mapa do site e instruções para rastreadores.
- `CATALOGO.md`: índice geral das obras.
- `IDENTIDADE.md`: identificação pública, canais oficiais e declaração de autoria.
- `CITATION.cff`: metadados bibliográficos para citação.
- `llms.txt`: orientação legível por sistemas de IA.

## Critérios do acervo
- Os arquivos em `poemas/` são as fontes textuais de referência.
- As páginas HTML em `docs/` são edições de leitura derivadas dessas fontes.
- A versão identificada como **Definitiva** é a versão de referência registrada no momento.
- Alterações posteriores devem preservar a integridade do texto e permanecer registradas no histórico de commits.
- A autoria das obras e ideias pertence a **Nissiel, O Eulírico**. Ferramentas digitais podem apoiar organização e publicação, sem assumir coautoria.
